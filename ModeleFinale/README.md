# 🎥 Modele finale pentru Lip Reading

Acest folder contine modelele folosite de modulele proiectului, organizate dupa scop. Fiecare subfolder are propriile destinatii de copiere.

---

## 🛠️ Organizare si path-uri pentru copiere

Toate path-urile sunt relative la radacina proiectului.

### `ModelsForPredictions`
Modele pentru predictii:
- `./lip_reading_demo_module/Models/`
- `./lip_reading_demo_web/core/lip_reading_demo_module/Models/`

### `ModelsForPreprocessing`
Modele pentru preprocesare:
- `./lip_reading_demo_web/core/models/`
- `./lip_reading_video_preprocessing/Models/`

### `ModelsForStartTraining`
Checkpoint-uri de start pentru antrenare:
- `./lip_reading_training_module/Models/`

**Important:** Modelele se copiaza doar in destinatiile asociate fiecarui subfolder.
